# Intel Arc A770 (Alchemist / DG2) tuning — SYCL backend

This branch (`a770-prism`) is the PrismML fork of llama.cpp with the SYCL backend tuned for the
Intel Arc A770 16GB. With it, an A770 runs at roughly the level of a GeForce RTX 5060 (CUDA) on the
same models: prompt processing on par, token generation at 90–93% for models up to 9B.

Write-up with charts (Japanese): [a770.html](a770.html)

The A770's measured DRAM read ceiling is about 434 GB/s (77% of the nominal 560 GB/s); the RTX 5060
reaches 426 GB/s (95% of 448). Token generation is bound by that read rate.

## What changed

- **Prefill:** quantized weights go straight into oneDNN's weight-decompression GEMM on XMX
  (u4/s8 weights + f16 group scales) instead of being converted to f16 first.
- **Gated DeltaNet (Qwen3.5 / Bonsai 2):** chunked prefill (C=32, SIMT dots/WU kernels + an ESIMD scan)
  and a dedicated one-token decode kernel.
- **Decode:** kernels written from the IGC assembly — sub-group block reads instead of the gathers IGC
  generated, XMX (DPAS via ESIMD) flash-decoding for f16/q8_0/q4_0 KV caches, a whole-block-per-lane
  Q4_0 mat-vec, and fusion of the small per-layer ops (norm + rotation, q/k norm + M-RoPE + KV write,
  DeltaNet gate/conv/output chains, gate/up + SWIGLU).
- **32-bit index math** in the small decode kernels: DG2 emulates 64-bit integer multiply/divide, which
  made some tiny kernels cost 10+ µs.

Most of this is gated on Alchemist (DG2) devices; other Intel GPUs keep the original paths.

## Build

```bash
source /opt/intel/oneapi/setvars.sh
cmake -B build-sycl -DGGML_SYCL=ON -DGGML_SYCL_F16=ON \
      -DCMAKE_C_COMPILER=icx -DCMAKE_CXX_COMPILER=icpx -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_SHARED_LINKER_FLAGS=-fsycl-max-parallel-link-jobs=64 \
      -DCMAKE_EXE_LINKER_FLAGS=-fsycl-max-parallel-link-jobs=64
cmake --build build-sycl -j
```

Run with `ONEAPI_DEVICE_SELECTOR=level_zero:gpu`. For long prompts on 9B models, `-ub 1024` or `-ub 2048`
raises prompt throughput further.

## Switches and diagnostics

| Variable | Effect |
|---|---|
| `GGML_SYCL_GDN_CK=0` | Use the previous token-blocked DeltaNet prefill |
| `GGML_SYCL_TIMELINE=1` | Per-op-group share of a decode token, from sub-group clock stamps recorded in the SYCL graph |
| `GGML_SYCL_SKIP_OPS=OP1,OP2` | Ablation: skip ops to measure their in-graph cost (output becomes garbage) |
| `GGML_SYCL_OP_TIMING=1` | Per-op GPU time (with `GGML_SYCL_ENABLE_GRAPH=0`) |

## Known issues

- `test-backend-ops` aborts in SET_ROWS f16 → pq2_0 (`set_rows.cpp:550`); this is present in the unmodified fork too.
- SYCL output is not bit-identical between runs.
